# Веб-приложение «Электронный дневник» (Online-Gradebook)

## Общее описание

Проект представляет собой веб-приложение для ведения электронного дневника учащихся. Пользователи (учителя, ученики, родители и администраторы) могут регистрироваться, входить в систему, просматривать, создавать, редактировать и удалять записи об успеваемости и домашних заданиях.

## Регистрация пользователя

Пользователь должен иметь возможность создать учетную запись.

### Требуемые поля:
- Электронная почта (email)
- Пароль
- ФИО пользователя (first_name, last_name, middle_name)
- Роль (ученик, учитель, родитель, администратор)

## Логин

- Пользователь вводит email и пароль для входа
- Проверка правильности введенных данных
- Отображение ошибки при неверных учетных данных

## Логаут

- Пользователь может выйти из системы

## Просмотр списка записей

- Отображение списка всех записей в дневнике (оценок и домашних заданий)
- Возможность фильтрации по предметам, дате, ученику
- Сортировка по дате или оценкам

## Создание записи

- Авторизованные пользователи (учителя и администраторы) могут создавать новые записи (оценки, домашние задания, объявления)
- Валидация данных (формат даты, диапазон оценки от 1 до 5)
- Уведомление об успешном создании записи

## Просмотр деталей записи

- Отображение полной информации о конкретной записи (предмет, ученик, дата, оценка, домашнее задание)
- Возможность для родителей и учеников просматривать оценки и объявления

## Редактирование записи

- Авторизованные пользователи (учителя и администраторы) могут редактировать записи
- Валидация обновленных данных (диапазон оценок от 1 до 5)
- Уведомление об успешном редактировании

## Удаление записи

- Авторизованные пользователи (учителя и администраторы) могут удалять записи
- Подтверждение удаления (диалоговое окно)
- Уведомление об успешном удалении

## Типы пользователей:

1. **Ученик** — может:
   - Просматривать свои оценки и домашние задания
   - Просматривать объявления

2. **Учитель** — может:
   - Просматривать все записи
   - Создавать, редактировать и удалять записи (оценки, домашние задания, объявления)
   - Фильтровать записи по предметам, дате, ученику

3. **Родитель** — может:
   - Просматривать оценки и домашние задания своих детей
   - Просматривать объявления

4. **Администратор** — может:
   - Все возможности учителя
   - Управление пользователями и предметами

## Сущности базы данных

### User (Пользователь)
- user_id (PK)
- email (UNIQUE, NOT NULL)
- password (NOT NULL)
- first_name (NOT NULL)
- last_name (NOT NULL)
- middle_name (NULL)
- role_id (FK → Role, NOT NULL)

### Role (Роль)
- role_id (PK)
- role_name (UNIQUE, NOT NULL)
- description (NULL)

### Student (Ученик)
- student_id (PK)
- user_id (FK → User, UNIQUE, NOT NULL)
- class (NOT NULL)

### Teacher (Учитель)
- teacher_id (PK)
- user_id (FK → User, UNIQUE, NOT NULL)
- classroom (NOT NULL)

### Parent (Родитель)
- parent_id (PK)
- user_id (FK → User, UNIQUE, NOT NULL)

### Parent_Student (Связь родитель-ученик)
- parent_id (FK → Parent)
- student_id (FK → Student)

### DiaryEntry (Запись в дневнике)
- entry_id (PK)
- date (NOT NULL)
- grade (CHECK: BETWEEN 1 AND 5, NULL)
- homework (NULL)
- student_id (FK → Student, NOT NULL)
- teacher_id (FK → Teacher, NOT NULL)
- subject_id (FK → Subject, NOT NULL)

### Subject (Предмет)
- subject_id (PK)
- name_of_subject (UNIQUE, NOT NULL)

## Связи между сущностями

- User ↔ Role: один-к-одному (один пользователь имеет одну роль)
- User ↔ Student: один-к-одному (один пользователь может быть одним учеником)
- User ↔ Teacher: один-к-одному (один пользователь может быть одним учителем)
- User ↔ Parent: один-к-одному (один пользователь может быть одним родителем)
- Student ↔ Parent: многие-ко-многим (через Parent_Student)
- DiaryEntry → Student: многие-к-одному (много записей к одному ученику)
- DiaryEntry → Teacher: многие-к-одному (много записей к одному учителю)
- DiaryEntry → Subject: многие-к-одному (много записей к одному предмету)
